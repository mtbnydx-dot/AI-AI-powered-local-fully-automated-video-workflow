# 开发与部署约定

## 代码与运行环境

- 本项目管理自有业务代码、ComfyUI workflow、Prompt、配置、部署脚本与版本清单。
- ComfyUI、所需第三方节点和 vLLM 作为外部运行组件管理版本与依赖，无需将完整源码并入本项目。
- 模型、素材、产物和日志放在数据盘，路径通过配置指定。

## 离线部署与验证

按 B200 节点允许常驻服务的前提设计。在线开发机准备代码、模型和运行依赖，离线节点从挂载盘加载，运行时使用本地资源。

```mermaid
flowchart LR
    A["在线开发机<br/>拉取代码、模型与依赖"] --> B["数据盘<br/>运行环境、模型、脚本包"]
    B -->|"挂载并读取"| C["离线 B200 节点<br/>CLI 运行生产流程"]
    C --> D["写回数据盘<br/>视频、评审报告、日志"]
```

| 环境 | 用途 |
| --- | --- |
| CPU | 模拟推理，验证流程与接口，无需真实部署大模型 |
| PRO6000 等单卡 | 验证真实视频生成，评审推理可模拟 |
| 8 卡 B200 | 部署生产流程，验证 GPU 配置与吞吐 |

每次运行记录脚本包与镜头关联、模型和 workflow 版本、实际参数与 seed、产物路径、评审结果、耗时与错误，用于复盘和调参对比。

## 开发约束

- 遇到不熟悉的功能，先检索 GitHub 上维护活跃、许可证明确的同类项目，比较实现思路、依赖和已知问题，优先借鉴已验证设计。
- 不直接复制许可证不兼容或来源不明的代码。
- 为推测性或极少发生的竞态、安全边界增加复杂机制前，先说明具体问题、触发条件、发生概率及依据、实现与维护成本，并取得用户明确同意。没有统计时注明概率未知，不以理论健壮性扩大范围。
