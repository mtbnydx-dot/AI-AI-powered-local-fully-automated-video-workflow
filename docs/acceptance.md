# 8×B200 改造验收标准

本轮在 `dev-jz` 离线生产模块上实施改造，工作分支为 `kk-8xb200`。不修改在线脚本包生成，不开发 UI。下表列出验收要求；CPU 和 HTTP 契约测试不能代替真实 B200 验收。

| 范围 | 验收证据 |
| --- | --- |
| CLI 与输入 | 样例脚本包可校验、运行；提示词逐字保持，参数覆盖不能绕过；首帧与审核参考角色明确 |
| CPU 全流程 | 实际参考图生成预览片段、剪辑、导出可解码 MP4；CPU 推理替代明确标识 |
| Review 与返工 | 只审镜头画面；轻微瑕疵记录警告，明确失败仅换 seed；自动最多 3 次；预算耗尽或服务不可用选择已有可用 take 并标注降级 |
| 阶段顺序 | 逐片审核/选择后超分，再全部等齐拼接；超分保留音轨、帧率和实测时长；最终编码不二次超分 |
| 状态与复盘 | 文件保存运行状态、参数、模型/workflow 配置、评审与日志，可继续运行和定点重跑 |
| 推理接入 | ComfyUI 提交/查询/下载真实适配；vLLM 多模态请求与结构化评审真实适配；通过本地 HTTP 契约测试 |
| GPU 部署准备 | 7 卡生成/超分与 1 张整卡审核/可选 ASR；审核有限并发、共享显存预算及离线启动配置；真实节点验证模型兼容与峰值 |
| 续跑与预算 | 已保存 ComfyUI 任务 ID 恢复查询下载，不重复提交；普通 resume/retry 不重置预算；显式新制作轮不清除累计历史 |
| ASR 与字幕 | 默认关闭；启用后按成片真实时间戳转写和对齐，差异只报警；失败记录状态，不编造台词或时间轴 |
| 人工审核与交付 | 正常生产等待人工成片终审；显式 CPU 验收可使用 auto-approve；交付视频和生产记录保留降级标记 |

编排采用 Python 单进程与有限并发；状态采用每次运行的 JSON 文件，事件采用 JSONL。外部服务分别运行，不引入数据库、消息队列、认证或分布式锁。

CPU 验收证明流程和协议工作，不证明 H3/Qwen 的 GPU 兼容性、画质或吞吐。
