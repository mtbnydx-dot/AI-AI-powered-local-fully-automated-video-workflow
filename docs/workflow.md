# 生产工作流

本次改造只覆盖离线视频生成，线上脚本包生成保持原有职责。离线端使用冻结的有效提示词及资产，先生成并审核片段，再超分、合成和生成音频报告。交接字段见 [交接标准](handoff.md)，操作边界见 [agent 工作指南](agent-guide.md)。

```mermaid
flowchart TD
    subgraph S["脚本包生成：在线侧，本轮不修改"]
        A["Idea / 小说 / 原始素材"] --> B["改编剧本与分镜规划"]
        B --> C["准备角色、场景参考图<br/>镜头 Prompt 与创作约束"]
        C --> D["完整脚本包"]
    end

    subgraph V["视频生成：离线生产流程"]
        D --> E["校验并保存运行输入快照"]
        E --> F["生成队列：GPU 0–6<br/>生成 take 并记录 seed"]
        F --> G{"审核队列：GPU 7<br/>只判明显画面问题"}
        G -->|通过| U["保留片段"]
        G -->|拒绝且本轮生成少于 3 次| F
        G -->|拒绝且预算耗尽| X["随机保留已完成可解码 take<br/>记录问题"]
        G -->|审核不可用| Y["随机选择已有可用 take 并告警"]
        X --> U
        Y --> U
        U --> H["片段超分：生成池"]
        H --> W{"本集片段全部就绪"}
        W -->|是| P["按顺序合成成片"]
        W -->|继续剩余镜头| F
        W -->|有终态缺失| M["报告缺失<br/>其他独立任务继续"]
        P --> A1["可选 ASR 子进程：GPU 7"]
        A1 --> A2["Qwen 文字差异：只记录"]
        A1 --> A3["原台词 + 可靠识别时间 → 字幕<br/>无法对齐则记录遗漏"]
        P --> K{"人工终审"}
        A2 --> K
        A3 --> K
        K -->|通过| N["最终编码与交付质检"]
        K -->|明确指定额外制作轮| F
        N --> O["最终视频与生产记录"]
    end
```

每镜头每个制作轮最多 3 次生成，包含首次；控制和审核不改提示词，只按记录更换 seed。预算耗尽的可用片段继续走超分与合成，并保留未通过标记。没有可解码视频的镜头报告缺失，不以无限等待或新增人工审计代替错误处理。

普通 `resume` 和 `retry` 保持本轮预算；只有显式 `retry --new-round` 才开启额外制作轮，历史累计次数保留。ASR 关闭、不可用、文字差异或字幕未对齐均不触发重生成，不增加人工闸门。正常生产保留最终人工终审；CPU 配置和 `--auto-approve` 可用于无人值守验证，不能据此宣称已完成真实 B200 验收。
