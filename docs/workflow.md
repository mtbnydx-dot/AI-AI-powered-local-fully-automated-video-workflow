# 生产工作流

脚本包生成优先级较低，允许半人工半自动，可使用闭源大模型生成参考图。输入为 idea、待改写小说等原始素材，输出包含剧本 Markdown、参考场景与图片、正负 Prompt 等视频生产所需内容。

```mermaid
flowchart TD
    subgraph S["脚本包生成：在线侧，允许人工参与"]
        A["Idea / 小说 / 原始素材"] --> B["改编剧本与分镜规划"]
        B --> C["准备角色、场景参考图<br/>镜头 Prompt 与创作约束"]
        C --> D["完整脚本包"]
    end

    subgraph V["视频生成：离线生产流程"]
        D --> E["脚本包校验与任务准备"]
        E --> F["按镜头生成视频片段"]
        F --> G{"逐镜头自动审核"}
        G -->|通过| H["剪辑与合并"]
        G -->|未通过| R["定位问题，决定修复范围"]

        H --> I{"整片自动审核"}
        I -->|通过| J["输出待人工审片版"]
        I -->|未通过| R

        R -->|镜头问题：局部重生成| F
        R -->|剪辑问题| H
        R -->|超出重试预算或无法解决| M["暂停，人工介入"]

        J --> K{"人工审核"}
        K -->|通过| L["超分与最终编码"]
        K -->|修改意见| R
        L --> N["交付质检"]
        N --> O["最终视频与生产记录"]
    end
```

返工以受影响的镜头或剪辑步骤为单位，并保留生成与评审记录。超出重试预算或无法自动修复时暂停，由人工介入；人工审核通过后再执行超分与最终编码。

初版自动修复执行受影响镜头的重生成。自由文本剪辑建议无法执行时进入人工介入分支，调整输入包后新建运行。CPU 配置和 `--auto-approve` 用于无人值守验证，正常生产配置保留人工审核步骤。
