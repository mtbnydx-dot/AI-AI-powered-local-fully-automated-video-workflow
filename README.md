# 本地 AI 创作工作台

基于 **ComfyUI + FastAPI + 浏览器前端** 的本地图片与视频工作台。把模型安装、生成参数、工作流预检、任务跟踪和视频后期整合到一个中文界面，适合不想手工连节点的使用者。

主线是多模型、按任务使用，不再要求先跑 Wan 草稿、再换大模型，也不要求走完固定的六个步骤。MiniMax H3、LTX、Wan、Qwen 等路线由平台选择对应的模型资产和节点图；底层推理仍由 ComfyUI 执行。

> 本仓库只包含程序、工作流模板和文档，不含模型、生成素材、Python 虚拟环境或个人密钥。首次安装需要网络与足够磁盘空间。接入、下载、预检通过和实际出片是不同状态，不能互相替代。

## 快速启动

1. 下载并解压仓库到可写目录，或使用 Git 克隆。
2. Windows 双击 `START_WORKFLOW.bat`；macOS 在终端执行 `bash ./START_WORKFLOW.command`。
3. 打开启动窗口给出的地址，默认是 `http://127.0.0.1:7860`。
4. 进入「环境与模型」，确认运行模式、ComfyUI 路径和模型下载目录，再选择目标模型。
5. 查看安装计划后准备缺失项；节点加载完成、工作流预检通过后，再进行短片测试。

启动器使用 Python 3.10–3.12，建议 3.12。它会优先准备项目自己的 `.venv` 并安装前端依赖；**打开前端不等于安装或启动了 ComfyUI**。详细操作和失败处理见[快速开始](START_HERE.md)。

## 系统如何工作

```text
浏览器：选任务、选模型、填参数、预览结果
  |
  | HTTP / 表单上传 / SSE 进度
  v
FastAPI：参数校验、模型解析、建图、预检、任务与文件管理
  |                         |                       |
  v                         v                       v
ComfyUI 本地推理          ffmpeg 本地后期         fal 云端 API（可选）
模型 + 编码器 + VAE       去闪 / 调色 / 拼接      上传素材并按服务计费
  |                         |                       |
  +-------------------------+-----------------------+
                            |
                       本地输出与任务记录
```

安装器是另一条链路：读取模型清单，准备 ComfyUI、节点依赖和权重。它不是推理引擎。完整模块与时序图见[技术架构](TECHNICAL_ARCHITECTURE.md)。

## 模型路线

| 路线 | 本平台的用途 | 重要边界 |
| --- | --- | --- |
| MiniMax H3 FL2VA | 文生、首帧/首尾帧、原生音视频、可选创作扩展 | 本地 CUDA 路线；原生、LightX、Spectrum 为不同采样档 |
| MiniMax H3 Ref2VA | 图片/视频/音频参考生成 | 独立权重，不能套用 FL2VA 的 LoRA 与控制扩展 |
| LTX 2.5 | 文生/图生、音视频、两阶段精修、可选自动时长 | INT8 / NVFP4 独立档位；不是 Mac 轻量 LTX |
| Wan2.2 / LTX 2.3 / HunyuanVideo | 其他质量、显存与输入需求 | 按对应档位安装，不混用编码器、VAE 和 LoRA |
| LTXV 0.9.8 / Mac Wan5B | 低显存或 Apple Silicon 路线 | 高内存 Mac Wan5B 为实验项，须短片验证 |
| Qwen-Image-2.1 等图片模型 | 生成或编辑关键帧 | 具体编辑能力、参考图上限由所选图片档位决定 |
| H3 Max by fal | 独立托管 API 路线 | 本平台接入的是云端服务，不是本地 H3 权重更新 |

目录中还可能出现「官方工作流」或「手动接入」条目：**能搜索到或下载，不代表平台已有对应生成适配器。** 以界面的接入状态和预检为准。

硬件推荐使用单卡显存、系统内存、平台策略及运行时状态，不是保证书。双 48GB 不会自动合成单任务可用的 96GB；Apple 统一内存也不能直接换算成 CUDA 显存。参见[教程中的硬件选择](BEGINNER_FRONTEND_GUIDE.md#3-选择模型与确认环境)。

## 操作方式

- **生成新视频**：直接进「视频生成」。需要控制画面时先准备图片，再选择 I2V；不需要时使用 T2V。
- **只处理已有视频**：直接进「视频处理」，上传或从作品选视频，不用先生成。
- **继续处理结果**：在该结果上选择下一工具，当前文件会作为新输入；不强制处理顺序。
- **自动后期**：生成前显式勾选，使用提交时的参数快照；失败即停，页面需要保持打开。
- **社交发布**：先选版式，分别核对模型画布与最终交付尺寸；平台不会自动发布到社交账号。

## 部署与边界

- **本机一体**：前端与 ComfyUI 在同机使用。
- **服务端 / 客户端**：生成服务器运行本平台 API；另一台电脑通过浏览器或客户端模式连接。客户端填写的是本平台地址，通常为 7860，不是 ComfyUI 的 8188。
- 这不是面向公网的多租户平台。远程令牌不是完整用户权限体系，不要直接开放 7860/8188 到公网。
- 自动后期不是服务端持久化编排引擎；任务记录也不是媒体备份。
- 去闪、插帧和超分不保证修复人物身份漂移、肢体错误或文字变形。
- 本地生成、安装、更新、重启、显存释放和云端付费是不同操作，执行前确认资源与授权。
- 人物素材须有使用授权。成人内容模式只允许明确成年、自愿且合法授权的素材；不得用于未成年人、非自愿内容或真人私密仿冒。
