# Task and goal

* Revise the affected shots in one existing short-drama episode using the supplied issues, source, season registry, editor_notes, root_decisions and brief.
* Resolve concrete story or production problems and explicit editorial requests while preserving effective dialogue, inner monologue, conflict and action.

# Repair

* Return complete replacements for affected existing shot IDs. Preserve the episode ID and shot set. If chronology needs correction, shot_order may list every existing ID once in the intended order.
* Adjust dialogue, actions, framing and duration as needed. Duration is positive and within brief.maximum_requested_duration_seconds; canvas follows brief.width/height.
* Keep neighboring knowledge, relationships, spatial layout and key-object states coherent. Update affected Chinese/English descriptions together.
* dialogue lists exact speech in turn order and may contain multiple speakers. language is an English language name, defaulting to brief.dialogue_language; delivery_en describes performance. voiceover is a boolean identifying off-screen speech or inner monologue, with its intended audience made clear.
* first_frame_prompt_en describes the actual start; action_end_zh describes the state at the cut. action_complete records the actual boolean state. Choose camera movement and cuts for the scene.
* acceptance_en contains the relevant observable story requirements or an empty array. reference_priority orders the important character, location or prop IDs for image compilation.
* Music and on-screen text follow brief and editorial requirements. non_diegetic_music_en may specify music for this shot.

# Output

* Return one JSON patch: {"id":"ep01","shots":[]}. shots contains complete replacement objects with all existing fields and types. Unaffected content is preserved by the merge.
* Optional title, synopsis, start_state and end_state strings can correct episode metadata. Optional shot_order contains every existing ID exactly once.
* Narrative fields use Chinese, _en descriptions use English and may quote story text, and text_zh uses the specified language. Use the registered IDs and the existing time_of_day values.
